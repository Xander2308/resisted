# ResisTD – Alpha 0.1

Build the path of most resistance. A maze tower defense for your phone.

## Online stellen (GitHub Pages)
1. Auf github.com: **+ → New repository**, Name z. B. `resistd`, **Public**, **Create repository**.
2. **uploading an existing file** anklicken und den *Inhalt* dieses Ordners hineinziehen
   (index.html, manifest.webmanifest, sw.js, README.md und die Ordner `img` und `icons`). **Commit changes**.
3. **Settings → Pages**: Source **Deploy from a branch**, Branch **main**, Ordner **/ (root)**, **Save**.
4. Nach 1–2 Minuten steht oben der Link (z. B. `https://DEINNAME.github.io/resistd/`).

## Update
Im Repository **Add file → Upload files**, neue `index.html` hineinziehen, **Commit changes**.
Link und Spielstände bleiben erhalten.

## Für Freunde
- Link in **Safari** (iPhone) bzw. **Chrome** (Android) öffnen – nicht im WhatsApp-/Instagram-Browser.
- **Teilen → Zum Home-Bildschirm** (iPhone) bzw. **⋮ → App installieren / Zum Startbildschirm** (Android).
- Dann läuft ResisTD wie eine App im Vollbild, auch offline, und der Spielstand bleibt erhalten.
- Backup vor einem Handywechsel: Pause → **Back up save** → Code kopieren; auf dem neuen Gerät **Restore save**.
- Dev-Modus (zum Testen): Link mit `?dev` am Ende öffnen.
